# Portofolio Badrus

Portfolio personal milik Mukhamad Badrus Sholeh yang menampilkan karya desain grafis, fotografi, dan prestasi akademik. Website ini dibuat sebagai landing page modern dengan gaya visual yang elegan dan minimal.

## Fitur

- Tampilan landing page yang modern
- Section tentang, karya, prestasi, dan kontak
- Filter karya berdasarkan kategori desain dan fotografi
- Desain responsif untuk desktop dan mobile
- Favicon custom menggunakan gambar dari folder Foto

## Struktur Project

```bash
Portofolio/
├── index.html
├── style.css
├── script.js
├── README.md
├── Foto/
│   ├── favicon.png
│   ├── Badrus.JPG
│   ├── Profile.JPG
│   └── ...
```

## Cara Menjalankan

Buka file `index.html` di browser secara langsung, atau jalankan server lokal sederhana jika ingin preview lebih aman, misalnya:

```bash
python -m http.server 8000
```

Lalu buka:

```bash
http://localhost:8000
```
