## 📌 Tentang Portofolio

Website portofolio ini dirancang dengan estetika *luxury dark theme* beraksen emas (*gold luxury*), memadukan presisi matematika, keindahan visual desain grafis, serta kedalaman narasi fotografi. Setiap elemen dibangun menggunakan **Vanilla Web Technologies** (HTML5, CSS3, & Modern JavaScript) tanpa framework berat untuk memastikan performa yang cepat, mulus, dan responsif di berbagai ukuran layar.

---

## 🚀 Fitur Utama

- **🧭 Opening Radar Screen & GPS HUD**: Layar pembuka futuristik bergaya radar GPS pemindai area Malang lengkap dengan animasi pemindaian, progress bar koordinat, dan tombol lewati (`[ESC]`).
- **✨ Luxury Smooth Custom Cursor**: Kursor ganda interaktif dengan efek *zero-lag lerp physics* dan animasi membesar pada elemen interaktif (hanya aktif pada perangkat non-touchscreen).
- **🌌 3D Ambient Background & Canvas**: Latar belakang dinamis dengan ambient grid dan partikel canvas yang responsif terhadap pergerakan kursor/layar.
- **🖼️ Interactive Dual Profile Photo**: Frame foto profil interaktif yang berganti sudut pandang foto saat disentuh atau diarahkan kursor (*hover/focus*).
- **🎨 Galeri Karya & Filter Kategori**: Filter instan untuk memilah karya antara kategori **Desain Grafis** dan **Fotografi**.
- **🔍 Modal Lightbox HD**: Pratinjau gambar beresolusi tinggi beserta takarir (*caption*) interaktif untuk karya dan bukti dokumentasi prestasi.
- **⚙️ Skill & Tools Carousel**: Galeri *slider/carousel* interaktif untuk software desain, tool kecerdasan buatan, serta teknologi pemrograman web.
- **🏆 Rekam Jejak Prestasi (Achievements)**: Daftar prestasi kompetisi (seperti Musabaqah Fahmil Qur'an & Olimpiade) yang dilengkapi modal dokumentasi bukti kegiatan.
- **📱 Navigasi Mengambang & Responsif**: Menu navigasi modern dengan *floating liquid style* dan tombol menu responsif untuk perangkat mobile.
- **✉️ Formulir Kontak Interaktif**: Form pesan langsung dengan validasi input dan tautan cepat ke WhatsApp, Instagram, TikTok, serta Email.

## 💻 Cara Menjalankan

Proyek ini merupakan aplikasi web statis murni sehingga tidak memerlukan proses *build* atau instalasi paket yang rumit.

### Opsi 1: Buka Langsung
Cukup klik ganda file [index.html](file:///d:/Portofolio/index.html) untuk membukanya langsung di peramban (Chrome, Edge, Firefox, Safari).

### Opsi 2: Menggunakan Live Server (VS Code)
1. Buka folder `Portofolio` di **Visual Studio Code**.
2. Klik kanan pada `index.html` lalu pilih **"Open with Live Server"**.

### Opsi 3: Menggunakan Server Lokal Sederhana

**Menggunakan Python:**
```bash
# Masuk ke direktori proyek lalu jalankan:
python -m http.server 8000
```
Buka browser di `http://localhost:8000`.

**Menggunakan Node.js (`npx serve`):**
```bash
npx serve .
```
